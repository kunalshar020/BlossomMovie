# Blossom Movie App

A movie app built with Swift and SwiftUI as a learning project.

## Purpose

The purpose of building this app was to learn and practice Swift and SwiftUI by creating a simple movie application.

## Tutorial

This app was built by following the [Blossom Build YouTube playlist](https://www.youtube.com/playlist?list=PLoo0y1fSJmbYjS3oWak2macSx7PC7rwAi).

You can also check out the [Blossom Build YouTube channel](https://www.youtube.com/@BlossomBuild).

## Built With

* Swift
* SwiftUI
* Xcode

## About

Blossom Movie App is a simple movie application built with SwiftUI. The main goal of this project was to get familiar with SwiftUI and learn how to build an iOS application.

## Learning

This project was mainly created as a learning exercise. It helped me understand the basics of SwiftUI and gave me some hands-on experience with building an iOS app.

I plan to keep improving the app as I learn more about Swift and SwiftUI.
